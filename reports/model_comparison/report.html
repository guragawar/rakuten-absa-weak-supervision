和其他模型比，本研究的方法站在哪里

生成日期 2026-10-13状态：全部实验已完成

结论速览

  • 新的日语编码器单独就很强。LUKE-ja、ModernBERT-ja 310M、XLM-R large 只做普通微调，负面 F1 就达到 0.74–0.76，追平或超过了此前本研究最好的配置（DeBERTa + E7/E8，0.7447）。
  • 在最强的底座上，弱监督预训练仍有增益，但变小了。ModernBERT-ja 310M 加上 E7/E8 后，test 负面 F1 提升 1.05pp（显著），是所有配置中最高的；但 valid 上方向相反，需要如实说明。
  • 隐式负面的提升在三个底座上都稳定。XLM-R、DeBERTa、ModernBERT 上分别 +1.43、+1.45、+1.68pp，全部显著。这是本研究最稳健的贡献。
  • 本地 LLM 远不如微调模型。4 个模型 × 2 种设定中最好的是 Swallow-8B 少样本（0.628），比多语言基线 mBERT（0.662）还低。
  • 食事（朝食/夕食）的问题，拆分评分也解决不了。即使把相关弱标签增加到 4 倍以上，两个方面都没有改善。

1. 为什么做这次比较

审查时最可能被问到的问题是：「换一个更新、更大的模型，或者直接用大语言模型，是不是就不需要你的方法了？」此前本研究只比较了 XLM-R、DeBERTa、东北大 BERT 三个底座，和先行研究也只能做「划分不同」的参考比较。这次在同一数据划分、同一评测口径下，补齐了论文中常见、对审查有说服力的比较对象。

2. 怎么比

  • 数据：Gold 语料，按评论划分（训练 42,469 / 验证 5,367 / 测试 5,356 句）。所有模型用同一份划分。
  • 编码器：与本研究基线 E1 完全相同的训练设定（ASL 损失、逐标签在 valid 上调阈值），只换模型；每个模型 3 个 seed。
  • LLM：不微调，提示词中给出原论文的 7 个方面定义与标注规则；零样本与少样本（20 个训练集例句）；贪心解码。
  • 主指标：负面聚合 F1（7 个负面标签合并计算）。隐式负面指不含感情词的负面标注上的检出 F1。
  • 检验：配对 bootstrap（2,000 次，多 seed 平均）。方括号内为 Δ 的 95% 置信区间，「显著」表示不含 0。
  • 预注册：模型清单、判定规则、发散处理规则都在跑实验前写定（docs/model_comparison_plan.md），途中的追加与修订均注明时间点。
  • 数据协议：所有推理都在研究室 GPU 上本地完成。按「楽天データセット」利用規約，Gold 文本不能发送到外部 API，因此没有比较 GPT-4o 等（见第 9 节）。

4. 结果二：在最强的底座上，弱监督还有没有用

按预注册规则，在 valid 负面 F1 最高的 ModernBERT-ja 310M 上追加了 E7（近年 200 万条评论）+ E8（3 个 seed）。把三个底座上的结果放在一起：

底座运行次数负面 F1 增益（pp）隐式负面增益（pp）正面 F1 增益（pp）
XLM-R baseE1 5 次 vs E8 9 次+1.91 [+1.10, +2.75] 显著+1.43 [+0.69, +2.18] 显著+0.17 [-0.14, +0.51]
DeBERTa-v3-ja3 vs 3+1.85 [+0.88, +2.86] 显著+1.45 [+0.64, +2.25] 显著+0.50 [+0.09, +0.92] 显著
ModernBERT-ja 310M（A'）3 vs 3+1.05 [+0.16, +1.95] 显著+1.68 [+0.90, +2.48] 显著+0.06 [-0.34, +0.47]

需要如实说明的一点：ModernBERT-ja 310M 上，test 负面 F1 提升显著，但 valid 负面 F1 为 0.7735 → 0.7690（-0.45pp），方向相反。底座越强，弱监督的整体增益越小，证据也越不一致。

另一方面，隐式负面的增益在三个底座上都在 +1.4~+1.7pp 之间且全部显著；正面 F1 基本不变。也就是说，评分弱监督主要改善的是「没有感情词的负面表达」，这一点不依赖底座。

7. 与先行研究数字的参考比较

下列研究都用同一语料，但数据划分与筛选各不相同，原论文的划分也没有随数据发布，所以只能作参考，不能说「超过了」。

研究设定报告的成绩
Nakayama et al., LREC 2022（原论文）14 标签，80:10:10 分层，BERT-MLC14 标签平均 F1 0.711
中山ら，NLP2021（日文版）14 标签，8:1:1，BERTmacro 0.68 / micro 0.72
味岡ら，JSAI 2024；西元ら，JSAI 2025筛出 48,353 句（去掉无标签句与同一方面正负并存句），5 折micro 0.765–0.782
林・浦野，JSAI 2026LUKE vs BERT，划分未写明负面 F1 0.66（「Macro」实为加权平均 0.71）

本研究在自有划分上：14 标签平均 F1 0.78–0.80，micro F1 0.82–0.85。差距的主要来源是更新的模型与逐标签调阈值，不能归功于本研究的方法；方法的效果只用同一划分内的比较来论证。

8. 食事（朝食 / 夕食）问题的结论

面板只有一个「食事」评分，而 Gold 分为朝食和夕食。我们用套餐名和正文关键词把食事评分拆成两个头，在两个数据规模上检验：

实验运行次数朝食负面（pp）夕食负面（pp）负面聚合（pp）
A5（2024 年池）3 vs 3+0.41 [-1.22, +1.97]+1.66 [-0.63, +3.84]+0.02 [-0.73, +0.73]
A5b（2021–24 年池）5 vs 5-0.71 [-2.12, +0.69]-0.16 [-1.94, +1.80]-0.27 [-0.94, +0.40]

A5b 中可判定的早餐差评 42,119 条、晚餐差评 8,403 条，都是 A5 的 4 倍以上，但两个方面仍然没有改善。结论：问题不在信号量，单靠对齐评分粒度不能改善朝食和夕食。论文中作为否定性结果报告，并把「朝食/夕食的瓶颈」列为今后的课题。

9. 对论文的影响与建议

  1. 主张的重心：从「我们的配置最好」调整为「评分弱监督在多个底座上都稳定改善负面，尤其是隐式负面」。前者会被更新的模型超越，后者在三个底座上都成立。
  2. 主表：保留 XLM-R 主线（预注册、证据最完整）；本报告的编码器比较与 A' 作为扩展实验写在同一章。
  3. 如实写出的限制：最强底座上增益变小且 valid/test 不一致；LLM 只比较了本地模型；食事问题未解决。

10. 需要请教授确认的事项

  1. 是否申请用 GPT-4o 等外部 API 做比较。利用規約第3条第5項只允许乐天认可的生成式 AI；NII IDR 的 FAQ 4-1 说明输入外部服务属于向第三方提供，需事先许可。必要性：审查时常被问到「和 GPT 比如何」；本地最强的 LLM 也明显弱于微调模型，加上 API 结果可以让结论更完整。若不申请，论文中按「数据协议限制」说明即可。
  2. 开发中使用 AI 编程助手时附带看到的少量原文（约十几到二十几句）是否需要报告或处理。
