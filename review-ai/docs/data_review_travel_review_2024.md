## 1. 结论先行

**可以用于研究，且价值很高**——但定位是**大规模弱监督/预训练语料**，
不是标注评测集。它与现有 ABSA 标注数据（travel_aspect_sentiment.tsv）同源
（酒店 ID 与 HotelMaster **100% 匹配**），恰好补上了当前隐式情感研究

使用前有两个必须处理的前置事项（见第 5 节）：
①确认与现有标注数据的**评论重叠**，防止训练/测试污染；
②确认数据**来源许可**（疑似楽天トラベル数据集，通常经 NII-IDR 协议获取，有使用条款）。

## 3. 对当前研究（隐式情感 + ABSA）的价值

### 3.1 直接价值：隐式负面样本的规模化开采 ★★★

当前隐式情感研究（implicit_sentiment.md）的对比学习（Task 5）受限于
标注数据里的隐式样本量。本数据提供了一条**远距离监督（distant supervision）**通路：

> 分项评分低（1–2 分）+ oseti 词典零命中的评论 → **隐式负面候选**，
> 规模可达数万条，正好作为对比学习的增广正样本对来源。

这能把 Task 5 从"只用 5.3 万标注句内部配对"升级为
"用 58 万评论开采隐式表达 + 标注句验证"，方法贡献显著增强。

### 3.2 方面级弱监督预训练 ★★★

分项评分是**评论级的方面情感标签**（虽比句子级粗，但免费且量大）。
可行方案：先用「评论文本 → 六项分项评分」做弱监督预训练（多任务回归/分类），
再在 5.3 万句子级标注上微调——这正是前期 Weak→Gold 两阶段训练思路在
ABSA 上的复活，且这次的"弱标签"质量远高于关键词规则（是用户本人打的分）。

### 3.3 评估与分析增强 ★★

- **按酒店聚合**：ID 与 HotelMaster 全通，可做"酒店方面口碑画像"的应用演示；
- **元数据分层分析**：出行目的/同行者维度上的情感表达差异（如商务客 vs 家庭客的抱怨方式）；
- **总体评分 vs 文本情感的错位样本**：总分 5★ 但文本含负面方面（或反之）的评论，
  本身就是隐式/混合情感的天然候选池。

### 3.4 潜在的独立研究素材 ★

77.5% 的评论带酒店官方回复（45 万对「抱怨→回应」），可支撑回复生成、
投诉应对策略分析等衍生课题（当前不建议分散精力，仅记录）。

## 5. 使用前必须处理的三件事

### 5.1 与标注数据的重叠检查（防污染，最重要）

`travel_aspect_sentiment.tsv` 的 12,476 条评论若有部分来自 2024 年同一平台，
用本数据预训练再在标注测试集上评估就会**数据泄漏**。
处置：写脚本对两边评论文本做规范化精确/近似匹配（如 MinHash），
命中的评论从本数据中剔除后再用于任何训练。**在此之前不要开始预训练实验。**

### 5.2 来源与许可确认

数据形态（楽天トラベル字段体系 + 匿名化用户 ID + HotelMaster 配套）高度疑似
**楽天数据集（经 NII-IDR 协议提供）**。需确认：
- 实验室是否签有正式使用协议、协议覆盖成员范围；
- 论文发表时的数据引用要求与再分发禁止条款（通常**严禁把原始数据推到任何远程仓库**）。
处置：已确认本文件在 `.gitignore` 排除范围外——**需立即加入 ignore 规则**（见 5.4）。

### 5.3 分项评分列的语义核验

六列评分与七方面的对应关系目前是推断。核验方法（半天工作量）：
抽取各列 1–2 分的评论各 100 条，用现有 `absa_asl_v1` 模型预测方面负面标签，
看哪个方面命中率最高，即可确认列→方面映射；顺带产出"评分-文本一致性"统计，可写进论文数据节。

### 5.4 工程处置（本次评估已发现的行动项）

- `gold/data/raw/` 目前**不在 .gitignore 中**，651MB 原始数据有被误提交风险 → 需添加 `review-ai/gold/data/raw/`；
- 解析入口应仿照 `prepare_absa_dataset.py` 写专用脚本（处理内嵌 tab 的 544 行），
  不要直接 `pd.read_csv`。

## 6. 建议的接入路径（不打乱现有计划）

本数据**不改变** implicit_sentiment.md 的 Task 1–4（诊断阶段照旧，用标注数据）。
建议在 Task 4 决策点之后接入：

1. **先做 5.1 重叠检查 + 5.3 列语义核验**（合计约 1 天）；
2. Task 5 对比学习：用"低分项评分 + oseti 零命中"从本数据开采隐式负面候选，
   扩充对比样本对（与原方案并跑消融：仅标注数据配对 vs + 开采数据配对）；
3. （可选，算力允许时）方面评分弱监督预训练 → 标注微调的两阶段实验，
   作为论文的第二个方法贡献点。
