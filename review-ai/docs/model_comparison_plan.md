## B. 大语言模型（LLM）对比（不微调，提示词推理）

| 模型 | 理由 | revision |
|---|---|---|
| `Qwen/Qwen2.5-7B-Instruct` | 广泛使用的多语言指令模型 | a09a3545 |
| `tokyotech-llm/Llama-3.1-Swallow-8B-Instruct-v0.3` | 日语持续预训练的指令模型 | 0858f50e |

- **提示词**（日语）：7 个方面的定义与标注规则取自原论文（Nakayama et al., 2022, Table 3 与 §3.2：只陈述事实不标注；隐含的意见要标注；同一方面可同时为正和负；愿望/建议按是否满意判断）。要求输出 14 个标签名的 JSON 列表，无则输出 `[]`。
- **两种设定**：零样本（只有定义）；少样本（固定 20 个训练集例句：14 个标签各至少 1 句，其余随机，seed 42）。
- **解码**：贪心解码（确定性），`max_new_tokens=96`。
- **解析**：取输出中第一个 JSON 数组；未知标签忽略；解析失败视为空预测，并报告失败率。
- **提示词确认**：只在 valid 的前 200 句上检查输出格式能否解析，不根据 test 结果修改提示词。
- 每个设定只有 1 次运行（贪心解码无随机性），与微调模型的多 seed 结果做配对 bootstrap。

## 预期（不作为判定标准，仅记录事前看法）
- 新的日语编码器与 DeBERTa 同等或略好；大模型版不一定好于 base（数据量 4 万句）。
- LLM 在少样本下仍明显低于微调模型，尤其在负面与隐式负面上（文献中 LLM 在细粒度 ABSA 上普遍低于微调模型）。

## 修订：LLM 输出的解析（2026-10-12 19:15，llm-jp / gpt-oss 尚无任何 test 结果时写定）

- **起因**：llm-jp 在 valid 前 20 句的格式确认中，有 5 句没有输出 JSON 数组，而是只写出标签名（4 句）或输出 JSON 对象（1 句）。预注册的解析规则会把这些当作「无标签」，低估模型的实际判断能力。判断依据只有输出格式的特征（是否含方括号、是否含标签名），未查看任何得分以外的 test 信息。
- **处理**：保留预注册的解析为**主结果（严格版）**；另加**宽松版**作为补充：没有 JSON 数组时，从输出中识别 14 个标签名。两种结果对所有 LLM 一律计算并报告，各自保存预测（`<name>.npz` 与 `<name>_lenient.npz`）。
- **已完成运行的处理**：Qwen 与 Swallow 的 4 个设定用保存的原始输出重新计分（`tools/llm_absa_eval.py --rescore`）。严格版结果与预测文件和此前**逐项一致**；宽松版仅 Swallow 少样本有 3 句改由标签名识别。
- **另一处修正**：llm-jp 的分词器会额外返回 `token_type_ids`，导致生成函数报错；改为生成时只传入 `input_ids` 与 `attention_mask`。对其他模型的结果没有影响。

### 对「预期」的核对

- 「新的日语编码器与 DeBERTa 同等或略好」：低估了。LUKE-ja（+3.20pp）、ModernBERT-ja 310M（+2.20pp）都显著高于 DeBERTa。
- 「大模型版不一定好于 base」：对 XLM-R 不成立，large 比 base 高 4.13pp。东北大 BERT large 没有对应的 base 版运行，无法直接比较；它高于 XLM-R base 与 DeBERTa，但低于 base 规模的 LUKE-ja。
- 「LLM 在少样本下仍明显低于微调模型」：成立。

### 结论

1. 换底座的影响（mBERT 0.662 → LUKE-ja 0.756，约 9pp）大于本研究方法的增益（1–2pp）；本方法是可以叠加在底座上的增量，不是最强模型的来源。
2. 弱监督预训练的增益在三个底座上都显著（XLM-R +1.91、DeBERTa +1.85、ModernBERT-ja 310M +1.05pp），隐式负面的增益大小一致（+1.43 / +1.45 / +1.68pp）；最强底座上整体增益变小且 valid 不支持。
3. 本地 LLM（7–20B，不微调）在本任务上明显低于微调编码器。GPT-4o 等外部 API 未实施（见上「不实施」一节）。
