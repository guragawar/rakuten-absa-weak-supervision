## 0. 共同协议

| 项 | 设定 |
|---|---|
| 底座 | XLM-R base（与主线 A1–A4 相同） |

| 参照组 A0 | 主线 E7 编码器（`checkpoints/absa_weak_pretrain_v1/encoder`）× E8 seed 42/43/44，**用新脚本重跑**（7 月的 seed43/44 只剩 metrics，且同 seed 不可复现，必须同条件重跑） |

| 判断用数据 | **结论方向只看 valid**（3 seed 均值）；test 仅用于最终报告与配对 bootstrap（`tools/multiseed_f1_bootstrap.py`，3 seed 平均，2000 次） |
| 主指标 | 负面聚合 F1（7 个负面标签合并计算） |

### 统计功效的提前说明
- 负面聚合 F1 的 3 seed 配对 bootstrap，95% CI 半宽约 ±1pp。
- 单标签（如朝食负面，测试集 284 例）CI 半宽约 ±2.3pp；夕食（198 例）更宽。单标签的改善需超过约 2.5pp 才可能显著。
- 同 seed 的运行间波动约 0.7pp，单次运行之差不作结论。

## A5 食事拆分（检验粒度假说）

- **改动**：E7 的食事头拆为朝食头、夕食头（7 个头）。标签规则见 `tools/prepare_ablation_weak_labels.py --mode meal_split`：正文关键词优先，其次套餐名；无法判定的负面 mask。
- **数据**：2024 训练集中，食事负面 20,817 条里可判定朝食 9,885（47%）、夕食 1,913（9%），无法判定 9,019（43%）被 mask。
- **假设 H5**：粒度对齐后，E8 的朝食负面 F1 提升（主），夕食负面 F1 提升（次）。
- **判定**：
  - 成立：valid 上朝食负面 F1 的 3 seed 均值高于 A0，**且** test 配对 bootstrap 中朝食负面 Δ 的 CI 不含 0。
  - 部分成立：valid 方向一致但 test CI 含 0 → 报告为「方向一致、未达显著」。
  - 同时检查：负面聚合 F1 不显著下降（CI 上界 > 0）。
- **预期风险**：夕食负面信号很少（训练约 1.9k），夕食可能无改善。

## A6 弱标签噪声过滤（RQ4 的干预实验）

- **改动**：正文未出现该方面关键词的负面标签被 mask（`--mode noise_filter`，词表同 RQ4）。非负面不变。
- **数据**：负面标签被 mask 的比例：立地 59%、部屋 31%、食事 26%、風呂 46%、サービス 44%、設備 48%。
- **两个对立假设**（不预设方向）：
  - H6a：去除「评分与正文不符」的噪声 → 负面聚合 F1 上升；
  - H6b：未提及关键词的负面仍含有用信号（关键词召回有限；立地在主线中提升最大但其提及率最低）→ 下降或不变。
- **判定**：test 配对 bootstrap 负面聚合 F1 的 Δ CI 不含 0 时，按方向判定 H6a 或 H6b；含 0 则「无显著差异」。另报告立地负面 F1 的变化。

## A7 E7 随机性（稳健性）

- **改动**：E7 的 seed 改为 43、44（数据、设定与主线相同），各接 E8 seed 42/43/44。
- **问题**：主线结论是否依赖 E7 seed=42 这一次预训练。
- **判定**：
  - 3 个 E7 seed（42 = A0）各自的 E8 负面聚合 F1 均值，全部高于 E1 全部运行的最大值（0.7143）→ 「结论不依赖 E7 seed」。
  - 同时报告方差分解：E7 seed 间方差 vs E8 seed 间方差。

## 执行顺序与资源
A0（E8×3）→ A5（E7 + E8×3）→ A6（E7 + E8×3）→ A7（E7×2 + E8×6）。
E7 每次约 1 小时（GPU 独占时），E8 每次约 5 分钟。E7 只保留 `encoder/`，中间 checkpoint 跑完即删。
脚本：`tools/run_ablation_queue.sh`。

### 按预注册标准判定

**A5 食事拆分 → 部分成立（方向一致，未达显著）**
- 主（朝食负面）：valid +1.27pp（方向一致）；test Δ+0.41pp CI[−1.22, +1.97]，不显著。
- 次（夕食负面）：valid −1.56pp，test Δ+1.66pp CI[−0.63, +3.84]（P=0.92），两者方向不一致 → 不作结论。
- 负面聚合：Δ+0.02pp CI[−0.73, +0.73]，无下降。
- 解读：粒度对齐带来的改善即使存在也很小（≤约 1pp 量级），在测试集规模下检测不出。夕食弱标签只有约 1.9k，信号不足。

**A6 噪声过滤 → H6b 成立（过滤有害）**
- 负面聚合 Δ**−1.08pp** CI[−1.87, −0.24]，显著下降（valid 也 −0.81pp，方向一致）。micro −0.56pp、正面 −0.39pp 也显著下降；朝食负面 −1.71pp 显著。
- 立地负面 +0.86pp n.s.（被 mask 比例最高的方面也没有受益）。
- 解读：正文未出现方面关键词的负面评分仍携带有用信号（关键词召回有限 + 评分反映的不满未必写成该方面的词）。**简单按关键词过滤弱标签会丢掉有效信号**，这是 RQ4 的干预性证据。

**A7 E7 随机性 → 结论不依赖 E7 seed（成立）**
- 3 个 E7 seed × 3 个 E8 seed 的 test 负面 F1 共 9 个值：0.7204–0.7333，**全部高于 E1 全部运行的最大值 0.7143**。
- 方差分解：E8 seed 间 sd 0.39pp，E7 seed 间 sd 估计≈0（小于 E8 seed 的噪声）。
- 各 E7 seed 对 E1（5 seed）：+2.07 / +1.96 / +1.71pp，均显著。

## A5b 食事拆分 · 大数据版（2026-10-12 追加预注册，跑实验前写定）

> **时间点说明**：A5b 是在看到 A5「部分成立」的结果之后才决定做的，属于**事后追加**的检验，不是最初计划的一部分。判定标准仍然在运行之前写定，论文中需按「追加实验」报告。

- **动机**：A5 只用 2024 年池，可判定为夕食的负面弱标签仅约 1.9k、朝食约 9.9k。检验「信号量不足」这一解释。
- **参照组 R**：现有 `checkpoints/E7_recent2M/encoder`（2021–24 年，1 epoch，6 头）× E8 seed 42–46（新脚本，含 valid 指标与 npz）。
- **A5b**：E7 设定与 `E7_recent2M` 完全相同（`weak_all` 池，`--min_source_year 2021 --num_epochs 1 --max_valid_samples 50000`，全年份统计算正样本权重），唯一区别是食事头拆为朝食/夕食（`--heads 1,2,3b,3d,4,5,6`，标签规则同 A5，套餐名取自 16 年原始文件）× E8 seed 42–46。
- **seed 数增至 5**：单标签样本少，多 seed 以降低运行间波动。
- **主指标**：朝食负面 F1；**次指标**：夕食负面 F1；**保护条件**：负面聚合 F1 不显著下降。
- **判定**：
  - 成立：valid 5 seed 均值高于 R，**且** test 配对 bootstrap 的 Δ CI 不含 0（分别对朝食、夕食判定）。
  - 方向一致但 test CI 含 0 → 「方向一致、未达显著」。
  - 两者都不成立 → 「信号量不是（唯一的）瓶颈」，与 A5 合并报告。
- **数据量**：生成后在下方「A5b 结果」中记录近年池里可判定的朝食/夕食负面标签数。

### A5b 结果（2026-10-12 21:20 追加）

运行：2026-10-12 18:41–21:08（GPU1），11 次全部成功（E7 1 次 + E8 2×5 次）。检验：`results/ablation_A5b_vs_ref.json`。

**数据量**：2021–24 年池（训练 2,033,583 行）中可判定的朝食负面 42,119、夕食负面 8,403，分别是 A5 的 4.3 倍与 4.4 倍。

|---|---|---|---|---|

**探索性观察（非预注册指标，多重比较下仅作参考）**：隐式负面 F1 +0.60pp，CI [+0.06, +1.12]。
